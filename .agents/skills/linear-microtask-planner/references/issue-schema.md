# Schema das issues

## Parent issue

- objetivo global e resultado observável;
- responsável;
- componentes sob ownership;
- contratos principais;
- critérios de conclusão global;
- links para plano geral e plano individual.

## Microtarefa

- ID do plano;
- contexto curto;
- objetivo observável;
- entrada e saída concreta;
- componentes, contratos e área de arquivos;
- dependências e itens desbloqueados;
- critérios de aceitação em checklist;
- testes e cenário no navegador quando aplicável;
- evidência esperada;
- estimativa e prioridade;
- responsável único.

Use relações reais do Linear para dependências; não deixe a única representação dentro do texto.
